## Overview

This project is a web application that allows users to analyze news headlines and detect fake news using machine learning models. It provides detailed metrics, sentiment analysis, and key phrase extraction to help users better understand the content.

## Features

- **News Analysis**: Analyze news headlines for authenticity.
- **Sentiment Analysis**: Understand the sentiment of the news.
- **Key Phrase Extraction**: Identify important phrases in the text.
- **Visualization**: View metrics like confusion matrix, sentiment breakdown, and more.
- **Dark Mode**: Supports light and dark themes.

## Tech Stack

- **Frontend**: React, Next.js, Tailwind CSS
- **UI Components**: Radix UI, Lucide Icons
- **State Management**: React Hook Form
- **Animations**: GSAP
- **Charts**: Recharts
- **Validation**: Zod
